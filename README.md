# This application is a simple implementation of Boids algorithm for simulating flocking behavior of birds.

It is written in Scala 2.13.15. Tests in ScalaTest 3.2.19.

* Algorithm was created by Craig Reynolds in 1986.
* Boids is an artificial life program, simulating the flocking behavior of birds.
* The name "boid" corresponds to a shortened version of "bird-oid object".
* The algorithm is based on three simple rules: separation, alignment, and cohesion.
* The rules are applied to each boid in the flock.
* The algorithm is used in computer graphics, robotics, and other fields.
* The algorithm is implemented in this application using Scala and ScalaFX.

## How to run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run the `BoidSimulation` object.
4. Enjoy the simulation.
